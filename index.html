คู่มือการใช้งานระบบติดตามงานก่อสร้างสถานีไฟฟ้า

PEA Construction Tracking System (PCTS) — แนะนำฟังก์ชันการทำงาน ขั้นตอนการปฏิบัติงาน และแนวทางการบันทึกข้อมูลครบวงจร

บทที่ 1: ภาพรวมระบบและระดับสิทธิ์การเข้าใช้งาน

แนะนำสถาปัตยกรรมระบบ PCTS Ver 3.1 และการแบ่งระดับสิทธิ์ความปลอดภัย

วัตถุประสงค์ของระบบ

ระบบ PCTS (PEA Construction Tracking System) พัฒนาขึ้นเพื่อเป็นเครื่องมือกลางสำหรับวิศวกร, ผู้ควบคุมงาน, คณะกรรมการตรวจรับ และผู้บริหาร ในการติดตามความก้าวหน้าโครงการก่อสร้างสถานีไฟฟ้าแบบเรียลไทม์ พร้อมระบบตรวจสอบภาพถ่ายพิกัด GPS และการลงนามตรวจรับอิเล็กทรอนิกส์

ตารางเปรียบเทียบสิทธิ์การใช้งาน (User Roles)

ระดับสิทธิ์ (Role) กลุ่มผู้ใช้งาน ความสามารถในระบบ การเข้าถึง
Viewer บุคคลทั่วไป, ผู้บริหาร, ช่างสำรวจ ดูภาพรวมโครงการ, ดูกราฟ S-Curve, Gantt Chart, แผนที่สถานี GIS, ดาวน์โหลดรายงาน PDF ไม่ต้องเข้าสู่ระบบ (เป็นสิทธิ์เริ่มต้น)
Editor ผู้ควบคุมงาน กฟภ., ผู้ช่วยผู้ควบคุมงาน ทำได้เหมือน Viewer + บันทึกผลงานประจำวัน, อัปโหลดภาพหน้างานพร้อมลายน้ำ GPS, ลงนามดิจิทัล 3 ฝ่าย เข้าสู่ระบบด้วยอีเมลที่ได้รับการอนุมัติ
Admin ผู้ดูแลระบบ, หัวหน้าแผนกก่อสร้าง ทำได้ทุกอย่าง + เพิ่ม/แก้ไข/ลบโครงการ, แก้ไขน้ำหนัก WBS, นำเข้าข้อมูล Excel (เบิกจ่าย 092), อนุมัติสิทธิ์ผู้ใช้ เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ
ขั้นตอนเมื่อลงทะเบียนใหม่: เมื่อผู้ใช้งานลงทะเบียนบัญชีใหม่ผ่านฟอร์ม "ลงทะเบียน" สถานะเริ่มต้นจะเป็น Pending (รออนุมัติ) ผู้ใช้งานจะต้องแจ้ง Admin ให้กดอนุมัติสิทธิ์เป็น Editor หรือ Admin ผ่านหน้า "จัดการสิทธิ์" ก่อนจึงจะสามารถแก้ไขข้อมูลได้

บทที่ 2: หน้าภาพรวมและแผนที่พิกัดสถานี GIS

การติดตามสถานะโครงการ การสลับมุมมอง และการใช้แผนที่ระบุพิกัดสถานีไฟฟ้า

การสลับมุมมองแดชบอร์ด (View Mode Switcher)

ในแถบเครื่องมือด้านบน สามารถเลือกรูปแบบการแสดงผลได้ 3 มุมมอง:

มุมมองการ์ด (Card View)

แสดงการ์ดโครงการพร้อมหลอดความก้าวหน้า เปรียบเทียบแผน vs จริง และยอดเบิกจ่ายสะสม

มุมมองตาราง (Table View)

แสดงรายการในรูปแบบตาราง เปรียบเทียบผู้รับเหมา ผู้ควบคุมงาน และสถานะอย่างกระชับ

แผนที่ GIS (GIS Map View)

แสดงพิกัดที่ตั้งของสถานีไฟฟ้าทั้งหมดบนแผนที่ประเทศไทย พร้อมป้ายชื่อและสถานะ

การใช้งานแผนที่สถานี GIS

  • ป้ายชื่อและเปอร์เซ็นต์ถาวร (Permanent Labels): หมุดทุกสถานีจะแสดงชื่อสถานีไฟฟ้า (เช่น ⚡ สฟ.สมุทรสาคร 18) พร้อมตัวเลข % ผลงานจริงและแถบสีสถานะบนแผนที่ทันทีโดยไม่ต้องคลิก
  • แถบเลือกสถานีด่วน (Substation Chips): ด้านบนแผนที่คลิกชื่อสถานีเพื่อบิน (Fly-to) พุ่งเข้าหาพิกัดสถานีนั้นพร้อมซูมเข้าและเปิดหน้าต่างสรุปข้อมูล
  • ปุ่มนำทาง GPS: ในหน้าต่างป๊อปอัปของสถานี มีปุ่ม นำทาง GPS สีเขียวสำหรับเปิดแอปพลิเคชัน Google Maps เพื่อนำทางไปยังสถานีไฟฟ้าได้ทันที

บทที่ 3: การติดตามผลงานโครงการ (WBS, S-Curve, Gantt)

การวิเคราะห์ความก้าวหน้าโครงการก่อสร้างสถานีไฟฟ้าอย่างละเอียด

แท็บข้อมูลในหน้ารายละเอียดโครงการ

เมื่อคลิกปุ่ม "ดูรายละเอียด" บนการ์ดหรือตารางโครงการ จะเข้าสู่หน้าจอติดตามที่มีแท็บสำคัญ 7 ด้าน:

1. แผนงาน/ผลงานก่อสร้าง (WBS): ตารางแจกแจงกิจกรรมย่อย วันที่เริ่ม-สิ้นสุด น้ำหนักงาน (%) และผลงานจริงที่ทำได้
2. Gantt Chart: แผนภูมิแท่งแสดงไทม์ไลน์ของแต่ละกิจกรรม สามารถสลับมุมมอง วัน / สัปดาห์ / เดือน ได้
3. S-Curve: กราฟเส้นเปรียบเทียบผลงานสะสมจริงกับเส้นแผนงาน พร้อมคำนวณค่าผลต่าง (Variance) และริบบิ้นประเมินสถานะ (ปกติ / ช้ากว่าแผน / ล่าช้าวิกฤต)
4. รูปภาพความก้าวหน้า (Gallery): คลังภาพถ่ายหน้างานจัดหมวดหมู่ตามกิจกรรม WBS สามารถคลิกเพื่อดูภาพขยาย
5. ปฏิทินปฏิบัติงาน (Calendar): ตารางปฏิทินแสดงรอบระยะเวลาของกิจกรรมในแต่ละวัน
6. เบิกจ่ายงบประมาณ: ข้อมูลเบิกจ่ายสะสม เปรียบเทียบแผนเบิกจ่ายกับผลเบิกจ่ายจริงตามรหัส 092
7. ตำแหน่งสถานี: แผนที่พิกัดเฉพาะสถานี แสดงรัศมีสถานี 300 เมตร พร้อมปุ่มคัดลอกพิกัด GPS และปุ่มเปิดนำทางใน Google Maps

บทที่ 4: การรายงานผลงาน ภาพถ่าย และลายเซ็นดิจิทัล 3 ฝ่าย

ขั้นตอนการบันทึกผลงานประจำวัน การประทับลายน้ำ GPS และการลงนามรับรอง

1. การบันทึกผลงานประจำวัน (สำหรับ Editor)

  1. คลิกเมนู "รายงานความก้าวหน้า" บนแถบเมนูด้านซ้าย
  2. เลือก โครงการ และเลือก แผนงานย่อย (Task) ที่ต้องการอัปเดต
  3. ใส่วันที่รายงาน และระบุ ผลงานจริงสะสมเฉพาะงานนี้ (%) (เช่น 65.00%)
  4. กรอกรายละเอียดงานที่ดำเนินการ และปัญหาอุปสรรค (ถ้ามี)
  5. แนบรูปภาพหน้างาน (รองรับการถ่ายสดจากกล้องมือถือ)
  6. คลิกปุ่ม "ส่งรายงาน" ข้อมูลจะถูกบันทึกและคำนวณ S-Curve ใหม่อัตโนมัติทันที

2. ระบบประทับลายน้ำ GPS บนภาพถ่าย (Anti-Tamper Watermark)

ระบบจะดึงพิกัด GPS ละติจูด-ลองจิจูดจากอุปกรณ์ วันที่ เวลา และสังกัด กฟภ. มาประทับลงบนมุมล่างของภาพถ่ายโดยอัตโนมัติ เพื่อยืนยันว่าเป็นภาพถ่ายจริงที่บันทึกจากสถานที่ก่อสร้างสถานีไฟฟ้า

3. การออกรายงาน PDF และลงนามดิจิทัล 3 ฝ่าย

ในหน้าบันทึกรายงานผล หรือในหน้ารายละเอียดโครงการ คลิกปุ่ม "รายงานผลการปฏิบัติงาน (PDF)":

  • สามารถเลือกช่วงวันที่ต้องการออกรายงาน และเลือกภาพถ่ายที่ต้องการแนบ
  • กล่องลายเซ็นดิจิทัล 3 ฝ่าย: สามารถใช้นิ้วมือหรือปากกา Stylus เซ็นชื่อสดบนหน้าจอได้ทันที ได้แก่:
    1. ผู้ควบคุมงาน กฟภ.
    2. ผู้รับจ้าง / หัวหน้าชุดงาน
    3. ประธานกรรมการตรวจรับพัสดุ
  • คลิก "พิมพ์รายงาน / ดาวน์โหลด PDF" เพื่อส่งออกเอกสารรายงานตามมาตรฐานราชการทันที

บทที่ 5: การบริหารจัดการโครงการสำหรับ Admin

คู่มือสำหรับผู้ดูแลระบบในการตั้งค่าโครงการ แผนงาน WBS และการจัดการสิทธิ์

การสร้างและแก้ไขโครงการ

ในเมนู "ตั้งค่าแผนงาน" (Admin) → แท็บ "จัดการโครงการ":

  • คลิก "เพิ่มโครงการใหม่" เพื่อกรอกชื่อสถานีไฟฟ้า, วงเงินงบประมาณ, ระยะเวลาสัญญา
  • ผู้ควบคุมงาน และ กรรมการตรวจรับ 3 ท่าน: สามารถระบุชื่อกรรมการตรวจรับพัสดุครบทั้ง 3 ท่าน เพื่อนำไปใช้ลงนามในรายงาน PDF
  • พิกัดละติจูด-ลองจิจูด: สามารถกรอกพิกัด GPS ของสถานีไฟฟ้า หรือกดปุ่ม ดึงพิกัดปัจจุบัน จากอุปกรณ์

การกำหนดกิจกรรมย่อย (WBS) และน้ำหนักงาน

ในแท็บ "เพิ่ม/แก้ไขแผนงานย่อย" สามารถเพิ่มรายการงาน กำหนดวันเริ่ม-สิ้นสุด และกำหนด น้ำหนักงาน (Weight %) โดยผลรวมของน้ำหนักทุกกิจกรรมในโครงการจะต้องเท่ากับ 100% พอดี เพื่อให้การคำนวณกราฟ S-Curve ถูกต้องแม่นยำ

การอนุมัติสิทธิ์ผู้ใช้งาน (Approve Roles)

ในแท็บ "จัดการสิทธิ์" จะแสดงรายการผู้ใช้ที่เพิ่งลงทะเบียนและมีสถานะ Pending Admin สามารถกดปุ่ม "อนุมัติ Editor" หรือ "อนุมัติ Admin" เพื่อเปิดสิทธิ์การบันทึกข้อมูลให้กับผู้ร่วมงานได้ทันที

บทที่ 6: การติดตั้งและใช้งานเป็นแอปมือถือ (PWA)

ขั้นตอนการติดตั้งระบบลงบนสมาร์ตโฟน แท็บเล็ต หรือคอมพิวเตอร์โดยไม่ต้องโหลดผ่าน App Store

1. การติดตั้งบน Android (Google Chrome)

  1. เปิดเว็บไซต์ระบบ PCTS ด้วยเบราว์เซอร์ Google Chrome
  2. ที่แถบเมนูด้านซ้าย ให้คลิกปุ่ม "ติดตั้งแอปมือถือ" หรือกดปุ่มเมนู 3 จุดของ Chrome
  3. เลือก "ติดตั้งแอป" (Install App) หรือ "เพิ่มไปยังหน้าจอหลัก"
  4. ไอคอน PCTS จะปรากฏบนหน้าจอโฮมของมือถือ สามารถแตะเปิดใช้งานแบบเต็มหน้าจอ (Standalone) ได้ทันที

2. การติดตั้งบน iPhone / iPad (Safari)

  1. เปิดเว็บไซต์ระบบ PCTS ด้วยเบราว์เซอร์ Safari
  2. แตะปุ่ม แชร์ (Share) ที่แถบด้านล่างของจอ (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลื่อนลงมาแล้วแตะ "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  4. แตะ "เพิ่ม" (Add) ที่มุมขวาบน ไอคอน PCTS จะปรากฏบนหน้าจอใช้งานเหมือนแอปจริง
ระบบซิงค์ข้อมูลเรียลไทม์ (Supabase Realtime Sync): เมื่อมีการอัปเดตผลงาน ถ่ายภาพ หรือแก้ไขแผนงานจากอุปกรณ์ใดๆ ทุกเครื่องที่เปิดใช้งานอยู่จะได้รับข้อความแจ้งเตือน (Toast Notification) และรีเฟรชข้อมูลให้ตรงกันโดยอัตโนมัติแบบเรียลไทม์
